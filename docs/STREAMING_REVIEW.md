## 界面

参考 Claude 官网的暖灰背景、安静的侧栏、衬线标题与克制动效。侧栏支持收起，语言、主题和退出集中到工作区菜单。去掉装饰轨道、重复的账号品牌标志和字母图标，修复登录品牌标志与底色没有居中的问题。

操作图标统一使用 Lucide，导航、按钮、关闭控件各自采用一致尺寸。同一工具栏按钮等高；按钮保留明确文字与实际动作。侧栏切换、菜单和页面切换加入轻量动效，并遵守减少动态效果的系统设置。

使用 Lucide 1.62.0 与 Floating UI DOM 1.8.0。依赖已固定并本地打包，无需运行时访问 CDN。Go 程序直接嵌入生成资源，使用者无需安装 Node。依赖许可证位于根目录 `THIRD_PARTY_NOTICES.md`，镜像同步包含该文件。

修改图标和菜单依赖后的重建方式：

```bash
npm ci --ignore-scripts
npm run build:ui
npm run test:ui
```

## 三种协议

| 接口 | JSON | SSE | 本轮补强 |
| --- | --- | --- | --- |
| OpenAI Chat Completions `/v1/chat/completions` | 已有转换 | 已有转换 | 心跳、取消传递、试聊解析 |
| Anthropic Messages `/v1/messages` | 已有转换 | 已有转换 | 标准 ping 和结构化 error，不再把错误当助手正文 |
| OpenAI Responses `/v1/responses` | 已有转换 | 已有转换 | 跨分片思考标签过滤、终态一致、心跳、试聊解析 |

试聊可选择三种接口、逐字或整段显示；支持现有文本、历史与图片请求转换。SSE 解析兼容任意分片、CRLF、注释、无空格的 data 行、多行数据及最后一条未换行事件。异常终止会提示错误，已经显示的正文保留。

这是网页会话到 API 的适配，不是完整官方平台复刻。现有工具调用通过网页提示词转换，token 使用量为估算；官方平台的服务端会话存储、完整 Responses 生命周期、内置搜索与计算机工具等没有因此自动获得支持。实际模型与权限取决于上游账号。

## 长等待

三个 API 的 SSE 在等待期间每 15 秒发送一次保活。Anthropic 使用 ping 事件，OpenAI 两种接口使用 SSE 注释。所有写入串行化并及时 flush，结束时等待心跳退出，防止心跳泄漏和竞态。响应声明禁止代理缓冲和内容变换。

客户端取消后，将请求上下文传递到上游网络请求与等待账号锁的过程。主动取消不会触发账号冷却。原网页镜像已有即时转发，保持该实现。

心跳可以避免部分空闲连接超时，不能绕过客户端设置的绝对超时，也不能在上游尚未返回时制造正文。是否逐字显示仍取决于上游真正何时发送内容。
